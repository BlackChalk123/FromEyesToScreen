# 随视 1.0 · UI 原型设计说明

本原型采用用户指定的 [Refactoring UI skill](https://github.com/edisonmbli/refactoring-ui-skill)，并结合项目内的「总结正式版开发经验教训」和「讨论人脸追踪窗口旋转 Demo」聊天。用户随后明确要求黑白灰，成品以此为准。

## 正式版首版边界

核心流程为 **B 站选片 → 点开视频 → 透明观看 → 随姿势旋转**。登录发生在选片官网中，不再使用可以播放视频的独立“登录窗口”。观看内容的生命周期不因打开设置或隐藏观看页而重建。返回选片会暂停原型的播放，避免两个内容同时发声。

保留画面大小、基础平滑、校准、角度微调、引导线和上次观看恢复。遮幕、运动点、自动锁定、复杂预设、背景管理、本地视频和文档入口不进入本轮界面。后续内容扩展不影响当前旋转容器的 UI 职责。

## 界面与交互

| 视图 | 主内容 | 主操作 | 辅助操作 |
| --- | --- | --- | --- |
| 选片 | 官网浏览流程示意、上次观看 | 继续观看；首次状态时由点开视频承担 | 粘贴链接、登录、搜索示例 |
| 观看 | 可旋转的内容画面 | 开启 / 暂停头部跟随 | 返回、校准、引导线、设置、全屏 |
| 设置 | 当前观看的少量参数 | 直接调节并保存 | 居中、恢复默认 |

底部 `PROTOTYPE CONTROLS` 是评审工具，独立于产品界面；原生应用不需要这块区域。支持静态预览、初次使用、跟随中、人脸丢失、摄像头不可用和视频加载失败六种状态。

## 黑白灰视觉系统

所有应用界面颜色均为零饱和度；风景图片保留原色。未引入 Tailwind、前端框架、网络字体或组件库。

灰阶由 skill 的 `generate_palette.py --grey --temperature neutral --extended` 生成。正文 `#181818`，次正文 `#555555`，辅助文字 `#6a6a6a`。表面为 `#fafafa` / `#fdfdfd`，主按钮为深灰底浅灰字。主操作、选中状态和跟随状态同时使用文字、形状或图标表达，不依赖颜色。

沿用 skill 的字号与间距阶：字号 12 / 14 / 16 / 18 / 20 / 24 / 30 / 36；间距 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96。字体使用系统无衬线，字重 400 / 600。9px 的字标、地理标注、页脚是装饰性排版，不承载关键操作；窄屏部分媒体标注随内容视口缩小。组内通常 8–12px，组间 24–32px。

8 / 12 / 16 / 24px 圆角分别对应控件、分组、窗口、特殊大容器；pill 只用于状态与提示。阴影使用 5 个统一层级。缺少的 token 应先补到 `tokens.css` 与 `design-tokens.json`，再用于组件。纯 HTML 不生成 Tailwind 配置文件。

键盘焦点、触控目标、减少动态效果及语义 token 参考了 skill 的 `15-beyond-the-book.md`；这些属于扩展指导，不是原书规则。

## 旋转原型的约束

画面固定 16:9。大小不会随着角度变化；允许角度根据当前尺寸和位置求连续安全范围。完整显示时在边界停止；允许裁切时按模拟姿势继续旋转。100% 完整适配时安全角度接近 0°，明确显示原因。

微调与校准只修改统一角度目标，然后经过基础平滑，最后执行空间限制。人脸丢失时保持当前角度。设置面板与引导线不拥有另一套角度管线。

这只是交互验证逻辑，不替代原生 MotionCore 的真实摄像头和观看舒适度验证。HTML 的低通平滑参数不得直接当成已验收的正式算法。

## 原型与正式能力的区分

- 图片、播放进度、音量及跟随状态为模拟。没有真实视频流、摄像头识别或声音。
- HTML 页面的桌面背景是透明效果示意，浏览器无法因此透视到 macOS 桌面。
- 选片区域是官网流程示意，不是新的 B 站客户端，也不是实时推荐。三个示例使用同一张照片的不同裁切。
- 登录按钮说明正式流程，可由用户主动打开 B 站官网；原型不收集账号、不展示假二维码或密码框。
- 偏好和最近链接 / 进度保存在当前浏览器的 localStorage。正式版持久化与共享网站登录数据由原生架构实现。
- 支持普通投稿 BV / av / 主站视频链接，保留 `p` 与 `t`；短链接明确提示原型不联网解析。输入其他站点或不合法链接会显示错误。

## 验证记录

已实际检查 1280×900 桌面与 375×812 窄屏截图。浏览、观看页未发现横向溢出。设置可滚动，Esc 关闭并恢复焦点。浏览器控制台未记录运行错误。

检查过开启跟随、水平校准、引导线、完整适配时安全范围为 0°、恢复默认、选片空结果、点开示例进入观看、非法站点链接拒绝、带分 P / 90 秒起播时间的有效链接、人脸丢失保持、视频错误重试，以及刷新后恢复最近内容。

`check_contrast.py` 检查声明的 7 组实际文字配色，全部通过 4.5:1，最低 5.18:1。照片上的文字另有暗色渐变或衬底保护；照片像素的逐点对比度不属于该矩阵结果。

按 skill 的 hierarchy → layout → typography → color → depth → images → finishing 顺序完成视觉复核，当前已检查页面无未解决的 P0 问题。全屏入口已接入浏览器 Fullscreen API；不同容器可能限制调用，失败时会提示，未将原型验证当成原生透明全屏验证。
