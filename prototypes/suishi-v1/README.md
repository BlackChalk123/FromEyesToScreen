# 随视 · 正式版 HTML UI 原型

优先打开 [单文件原型](../随视正式版UI原型.html)，内含样式、脚本和图片，无需安装依赖或联网。

当前目录为可编辑源码，直接打开 `index.html` 也可体验。需要本地服务时：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototypes/suishi-v1
```

然后访问 `http://127.0.0.1:8765`。默认进入观看预览；使用 `#browse` 查看选片页，使用 `#first` 查看首次使用。

- 下方滑杆模拟侧倾；“自动演示”模拟缓慢转头。
- “体验状态”切换正常与失败场景。
- `G` 引导线，`F` 全屏，空格播放 / 暂停，`⌘R` 校准，`⌘,` 设置。
- 按住 Option 拖动画面，双击居中。窄屏评审可以从设置中居中。
- 图片、播放、跟随及官网均为模拟；偏好 / 最近内容使用浏览器本地存储。

`DESIGN.md` 记录产品边界、引用聊天、设计规则、已检查范围与原型限制。`screenshots/` 为实际浏览器截图。原有 Swift Demo 和 `demos/随视动态演示.html` 未改动。
